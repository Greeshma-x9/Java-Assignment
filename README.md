# Java-Assignment: Student Council Election Tally System

# What is This about?

This is a simple Java program that automates student council elections. Instead of manually counting votes, this system takes votes from voters and automatically calculates the winner. It's fast, accurate, and prevents mistakes which commonly happens during the student council elections.

# How to Use:

1. Run the program: `java ElectionTallySystem`
2. Enter how many voters will vote
3. Each voter selects their candidate (1, 2, or 3)
4. The system shows results and the winner

# What It Does:

- Takes votes from voters through the console
- Checks if votes are valid (1-3 range)
- Counts all votes automatically
- Finds and displays the winner
- Shows vote count for each candidate
